# スプレッド資料（展開法）

相談内容に合わせて、舞が選ぶ／相談者に選んでもらうためのスプレッド一覧。

---

## 1. ワンオラクル（1枚引き）
最もシンプル。今日の指針や、Yes/No、ひとつの問いへの端的な答えに。

```
        [1]
```
- **1**：問いへの核心・今のあなたへのメッセージ

---

## 2. スリーカード（3枚引き）
時間の流れや、物事の構造を見たいときに。並びの意味は問いに応じて選ぶ。

```
   [1]   [2]   [3]
```
- 時系列型：**過去 — 現在 — 未来**
- 状況型：**現状 — 問題 — 対策（アドバイス）**
- 選択型：**選択肢A — 選択肢B — 助言**

---

## 3. ヘキサグラム（6枚＋1枚）
恋愛・人間関係・込み入った相談向け。

```
        [1]
     [6]   [2]
        [7]
     [5]   [3]
        [4]
```
- **1**：過去 / **2**：現在 / **3**：未来
- **4**：対策・打つ手 / **5**：周囲の状況・環境 / **6**：相手の気持ち・本音
- **7**：最終的な結論

---

## 4. ケルト十字（10枚）
最も本格的。人生の岐路や、多面的に深掘りしたい大きな問いに。

```
            [3]
            [10]
       [5]  [1]  [6]     [9]
           [2](横)        [8]
            [4]           [7]
```
- **1**：現在の状況（本質）
- **2**：目の前の障害・課題（1に交差）
- **3**：顕在意識・目標
- **4**：潜在意識・根の原因
- **5**：過去
- **6**：近い未来
- **7**：相談者自身の立場・姿勢
- **8**：周囲・環境からの影響
- **9**：希望と不安
- **10**：最終結果

---

## スプレッド選びの目安

| 相談の重さ・種類 | おすすめ |
|------------------|----------|
| 今日の一言、迷いをひとつ晴らす | ワンオラクル |
| 流れを知りたい、シンプルに整理したい | スリーカード |
| 恋愛・対人・相手の気持ち | ヘキサグラム |
| 人生の岐路、じっくり深く | ケルト十字 |
