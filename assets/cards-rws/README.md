# Rider–Waite–Smith 仮カード画像

このフォルダには、開発中の仮素材としてRider–Waite–Smithデッキ原作のスキャン78枚を収録しています。

- 原画：Pamela Colman Smith（Arthur Edward Waite監修）
- 原作初版：1909年
- 原画の権利状態：パブリックドメイン
- 取得元：<https://github.com/metabismuth/tarot-json>
- 取得元データのライセンス：MIT（`SOURCE-LICENSE.txt`）
- 画像サイズ：350×600 px

現代の再彩色版や市販版の画像とは異なります。将来、利用者提供の正式なカード画像へ差し替えることを前提としています。

ファイル名は `m00`–`m21`（大アルカナ）、`w01`–`w14`、`c01`–`c14`、
`s01`–`s14`、`p01`–`p14`（小アルカナ）です。
